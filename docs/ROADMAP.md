# Roadmap

This is a 12-month plan. Pairhold is in the planning stage and no milestone has started yet. Order and scope may change as we learn, especially from user research.

## M1: User research

Usability tests of pairing, recovery and conflict handling with 8–10 people, including older adults and screen reader users.

## M2: Protocol specification and threat model

A public specification of the sync protocol and a threat model, published for review before the core library is considered stable.

## M3: Core library

A Kotlin library on Automerge and libsodium, covering tasks, notes and recurrences.

## M4: Storage adapters

- Local folder
- WebDAV/Nextcloud
- Google Drive

## M5: Open UX kit

Jetpack Compose components, design files and guidelines for the pairing, recovery, device list, sync status and consent flows.

## M6: Import and export

- iCalendar (VTODO/VEVENT)
- CSV

## M7: Release 1.0

Documentation, a sample app, fixes from the security review, and the 1.0 release.
