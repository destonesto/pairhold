# Security Policy

## Project status

Pairhold is in the planning stage. There is no released code, so there are no supported versions yet. Do not use anything in this repository to protect real data.

## Cryptography

Pairhold does not implement custom cryptography. It is designed to use existing, reviewed primitives from [libsodium](https://libsodium.org/). Feedback on the design, the protocol specification and the threat model is welcome as soon as they are published.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/destonesto/pairhold/security/advisories/new).

Do not open a public issue for security problems.
